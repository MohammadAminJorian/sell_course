## 🌟 About The Project

**Online Course Marketplace** is a Django web application designed for selling and purchasing virtual courses online.

The project implements a complete course purchasing workflow along with user phone verification and a posting system.

This project also has a special place in my development journey because it was **my first Django project**, where I started building real-world web applications with Django.

# 🚀 Getting Started

Follow the steps below to run the project locally.

### 1️⃣ Clone the repository

```bash
git clone https://github.com/MohammadAminJorian/sell_course.git
cd sell_course
```

### 2️⃣ Create a virtual environment

```bash
python -m venv env
```

### 3️⃣ Activate the environment

#### Windows

```bash
env\Scripts\activate
```

#### Linux / macOS

```bash
source env/bin/activate
```

### 4️⃣ Install dependencies

```bash
pip install -r requirements.txt
```

### 5️⃣ Apply database migrations

```bash
python manage.py migrate
```

### 6️⃣ Create an administrator account

```bash
python manage.py createsuperuser
```

### 7️⃣ Run the development server

```bash
python manage.py runserver
```

Open the project in your browser:

```text
http://127.0.0.1:8000/
```
